# Rubric Loom Runner v1.0.2

This maintenance candidate pairs the one-download runner with Rubric Loom
Bundle v1.3.3 and hardens reuse of the persistent private runtime.

## What changed

- The stable managed launcher now executes a bounded Python 3.11–3.13 probe
  before selecting `user-data/runtime/.venv`. A missing, non-executable,
  damaged, hung, or unsupported cached interpreter falls back to the supported
  bootstrap Python so the bundle can repair the private environment.
- The outer managed and portable entry points also bound that probe before
  invoking Python, including Windows PowerShell 5.1 and PowerShell 7. Healthy
  private environments remain preferred; a stuck startup is stopped before
  trying the bootstrap interpreter.
- The paired bundle audits installed dependency versions against its exact
  lock, refreshes drifted packages with operator approval, and blocks a Word
  no-op save that still contains the synthetic rubric starter.
- Managed and portable launchers retain user data, isolate dependencies from
  system Python, and avoid reinstalling a healthy matching environment.
- Prepared-candidate CI checks out the exact recorded bundle commit, so it can
  verify the pair before the bundle tag exists. Published pairs continue to
  require the named ref and exact commit to agree.
