# Rubric Loom Runner v1.0.1

This maintenance release pairs the one-download runner with Rubric Loom Bundle
v1.3.2 and makes first-time setup clearer.

## For users

- Rubric Loom checks its required support packages when it opens, before the
  Unravel/Weave choice and before any file or folder path prompt.
- The setup card distinguishes an already installed Python interpreter from
  the Loom's private environment. A supported Python 3.11-3.13 installation is
  reused; Python itself is not reinstalled.
- The landing screen states that Rubric Loom is purely deterministic software
  running locally in Python and that no AI model reads or interprets files.
- The README and packaged start guide now give the current macOS
  **System Settings > Privacy & Security > Open Anyway** path for an unsigned
  first launch.
- The managed and portable release assets remain separate from source-code
  downloads and retain the same verified pairing, update, rollback, and
  persistent user-data boundaries.

## Exact pairing

- Runner: v1.0.1
- Rubric Bundle: v1.3.2
- Bundle commit: `8c97c7210a816a02e2487b7ae8b4696bc3236618`

Rubric interpretation, extraction, scoring, XML construction, package
validation, and Brightspace-facing outputs remain owned by the pinned bundle.
