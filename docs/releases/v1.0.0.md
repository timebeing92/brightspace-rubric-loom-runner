# Rubric Loom Runner v1.0.0

The first runner release turns the Rubric Bundle’s guided terminal experience
into a one-download application.

## For users

- One managed ZIP includes the exact runner and Rubric Bundle versions tested
  together.
- Double-click launchers are included for macOS and Windows; Linux uses the
  adjacent shell launcher.
- Python and dependency checks are automatic. Installation is offered only
  when needed and uses a private environment.
- Unravel, Bulk Unravel, the synthetic demonstrations, and Weave remain the
  bundle’s existing guided journeys.
- Inputs, outputs, settings, logs, and the private environment live outside
  replaceable version folders.
- Verified updates, one-step activation, rollback, and explicit old-version
  removal are available from the stable launcher.

## Trust boundary

The runner contains no rubric parser, scoring logic, XML builder, or package
validator. It supervises one exact `brightspace-rubric-bundle` release and
validates that release through repository, commit, contract, capability, and
runtime-file receipts.
